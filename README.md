**📊 Data Analytics Project**
**Overview**

This project demonstrates an end-to-end data analytics workflow, covering data loading, exploratory data analysis (EDA), data cleaning, SQL querying, and business intelligence reporting.
The goal is to transform raw data into actionable insights using Python, SQL, and Power BI, and present findings through a dashboard, report, and presentation.

**Dataset**

The dataset contains structured data relevant to business analysis.
It is loaded and processed using Python.
Data quality issues such as missing values, duplicates, and inconsistencies are addressed during the cleaning phase.

**Tools & Technologies**

**Python** – Data loading, EDA, and data cleaning
**Libraries –** Pandas
**MySQL Server** – Data storage and SQL querying
**SQL** – Data extraction and analysis
**Power BI **– Interactive dashboard creation
**Gamma** – Report writing and PowerPoint presentation

**Project Steps**

Data Loading
Imported the dataset into Python for analysis.
Exploratory Data Analysis (EDA)
Analyzed data distributions, trends, and relationships.
Identified missing values and outliers.
Data Cleaning
Handled missing values and duplicates.
Corrected data types and standardized formats.
SQL Analysis
Loaded cleaned data into MySQL Server.
Wrote SQL queries to answer key business questions.
Dashboard Development
Built an interactive Power BI dashboard to visualize KPIs and trends.
Reporting & Presentation
Created a detailed analytical report.
Designed a presentation (PPT) using Gamma to summarize insights.

**Dashboard**

The Power BI dashboard provides:
Key performance indicators (KPIs)
Trend analysis and comparisons
Interactive filters for deeper insights
Results & Insights
Delivered clear insights derived from cleaned and structured data.
Enabled data-driven decision-making through SQL analysis and visual reporting.
Presented findings in a professional, business-ready format.
